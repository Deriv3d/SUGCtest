# Claims

| ID | Claim | Status | Evidence / settling check |
| --- | --- | --- | --- |
| C-001 | The game is a PPU frontend wrapping one embedded Genesis emulator that runs bundled ROM images. | confirmed (structure), details unknown | Lab night 1: the disc ships one executable and no PRX/SELF; one zlib-packed archive in USRDIR holds 147 entries, of which 40 carry a Mega Drive header and 2 a Master System/Game Gear header, at standard cartridge sizes. Executable strings name the CPUs and the emulator. Phase 1: hand-off path and archive contents now documented (C-011 to C-014). |
| C-002 | Ghidra has a big-endian PowerPC64 language with 32-bit addressing suitable for PS3 PPU code. | confirmed (tooling) | `PowerPC:BE:64:64-32addr` is defined in Ghidra's `Processors/PowerPC/data/languages/ppc.ldefs` (master, checked 2026-10-06). Not yet tried on this game's ELF. |
| C-003 | Ghidra fails on Cell-specific VMX load/store instructions in this game. | negative | Lab night 1, Ghidra 12.1.3: 1 bad instruction in the whole executable, and it looks like data. 200 of a random 200 functions decompile without errors (16 with warnings, mostly unrecovered jump tables). |
| C-004 | A maintained Ghidra processor module for the Cell SPU exists. | unknown | Web and GitHub searches on 2026-10-06 found none. Not yet a negative: searches were not exhaustive. |
| C-005 | The game uses the SPU. | confirmed | One SPU ELF embedded in the executable, laid out as a SPURS taskset task (not a job). The game creates its own 3-SPU SPURS instance but no SPU work was visible in the first 60 s of boot. A separate 4-SPU SPURS instance belongs to the system video library used for FMV playback. The game imports both taskset and job-chain SPURS functions. What the task does: unknown. |
| C-006 | Ghidra 12.1.3 with Ps3GhidraScripts names every PPU import. | confirmed | Lab night 1: 250 of 250 imports named from NIDs across 17 Sony modules; entry point found; 5,956 functions. The r2 cspec tweak made no measurable difference. |
| C-007 | RPCS3 can decrypt the executable and boot the game without its GUI. | confirmed | RPCS3 0.0.43-20227: `--decrypt` gives the same SHA-256 on two runs; `--no-gui` boot ran about 90 s and appeared to render. |
| C-008 | Ghidra addresses agree with RPCS3 at runtime. | confirmed | Lab night 2: entry descriptor and 5 import stubs match RPCS3 memory and log; 2 stubs also hit by live GDB breakpoints at exactly Ghidra's address (interpreter mode only). Code segment in guest memory is byte-identical to the decrypted ELF. |
| C-009 | Title-screen frames are reproducible by wall-clock wait. | negative | Lab night 2: two runs with the same 40 s wait captured frames 2164 and 2171; the title screen animates. Golden captures must key on frame number or a savestate. |
| C-010 | RPCS3 0.0.43 can create an RSX capture without the GUI. | negative | Lab night 2: no CLI or config path; only menu or hotkey, and synthetic keystrokes are blocked on the owner's machine. Manual capture required. A manual capture made from the menu fails to replay in the same build (`--rsx-capture`: fatal "context alloc failed" in the replay thread). |
| C-011 | The FPG archives are flat tables of CRC-32 name hashes pointing at zlib streams padded to 2 KiB. | confirmed | Layout in `knowledge/formats/fpg.md`. 69 of 147 `flog_u` hashes reproduced from executable strings with the documented hash; `sugc-lab roundtrip` rebuilds both archives byte for byte; all 159 streams decompress to the table size. |
| C-012 | The game serves asset names from the archives before the disc. | confirmed | Ghidra: virtual-file open 0x000f2030 calls archive lookup 0x00054430 for both archives before the `cellFs` fallback 0x00056b70. |
| C-013 | ROM images reach the 68000 memory map unmodified. | hypothesis | Ghidra: machine builder 0x0014dd40 maps the inflated buffer from 0x000fa998 with no rewrite or patch in between. Settling check: GDB dump of guest memory while a game runs, compared with the inflated archive entry. |
| C-014 | Each Genesis game picks one of up to three regional ROM names from a region global. | confirmed (code) | Ghidra: 40 per-game routines call 0x0014dd40 with three name arguments; the region read is 0x000fa3c8. Which names exist per game: not yet tabulated. |
| C-015 | Bundled Genesis ROMs carry valid internal checksums. | confirmed (38 of 40) | Lab: header checksum (sum of big-endian words from 0x200) matches in 38, fails in 2; the ROM-end field matches the image size in all 40. Failures are not yet explained (retail quirk vs patch). |
